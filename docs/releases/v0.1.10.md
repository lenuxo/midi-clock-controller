# MIDI Clock Controller v0.1.10

## Changes

Independent devices now offer **Start with master**, off by default. Enable it to launch a stopped device with the next master Start or Continue at its own BPM. Devices already playing keep their current playback. Master Stop leaves started independent devices playing, and Stop All stops every local output.

With Link enabled, these devices use the selected launch boundary, then run on their own local clock. Pending starts can be cancelled individually or with the master. The option lasts for the current device instance. Reconnecting still requires a manual start.

## Install and update

Requires Apple Silicon and macOS 13 or later. In v0.1.9 or later, choose **Check for Updates…**, then download and install. Installation stops local MIDI and relaunches the app.

For manual installation, quit the old app, open the DMG and drag **MIDI Clock Controller** into **Applications**. The app uses an ad-hoc signature and has not been notarized. If macOS blocks first launch, confirm the download source and use **System Settings → Privacy & Security → Open Anyway**.

Download the matching checksum and run:

```sh
shasum -a 256 -c MIDI-Clock-Controller-v0.1.10-macOS-arm64.dmg.sha256
```

The GPL-2.0-or-later source attachment includes project sources and pinned dependency metadata. Build on macOS using `zsh scripts/build-app.sh`, then `zsh scripts/build-dmg.sh`. The first build downloads Sparkle. Signed in-app updates use the existing publisher key and the included appcast.xml.

## 中文说明

独立设备新增默认关闭的「随主控启动」。开启后，停止中的设备会随下一次主控开始或继续启动，保持自身 BPM。已经运行的设备继续播放。主控停止后，已启动的独立设备继续运行，可单独停止或使用「全部停止」。

启用 Link 时，独立设备对齐所选启动边界，随后按本地速度运行。等待启动可单独取消，也可由主控取消。设置保留在当前设备实例中，重连后仍需手动启动。

v0.1.9 用户可通过「检查更新…」下载并安装。也可退出旧版后打开 DMG，将应用拖入「应用程序」。安装更新会停止本机 MIDI 并重启应用。附件包括完整对应源码、签名更新包、更新清单和校验文件。

## Validation

89 tests passed, including private-port CoreMIDI integration. Two isolated-network Link tests were skipped. Debug preview checks covered light/dark layouts, scrolling, master launch, master stop and Stop All. Physical MIDI and real Link network behavior were not measured in this release run.
