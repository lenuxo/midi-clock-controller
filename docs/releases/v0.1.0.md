# MIDI Clock Controller v0.1.0

首个发布版本：macOS 原生 MIDI 主时钟，支持多设备主控同步和独立调速。

## 下载与系统要求

- 下载附件 `MIDI-Clock-v0.1.0-macOS-arm64.zip`，其中包含 `MIDI Clock.app`。
- 需要 Apple Silicon（M 系列芯片）Mac、macOS 13 或更高版本。本次二进制附件不支持 Intel Mac。
- 运行应用无需安装 Xcode、Swift 或第三方依赖。GitHub 自动生成的 Source code 附件是源码，不是可直接运行的应用。
- 本版本使用本地 ad-hoc 签名，尚未使用 Developer ID 签名及 Apple 公证。

## 安装

1. 下载 ZIP，双击解压。
2. 将 `MIDI Clock.app` 拖入「应用程序」文件夹，再双击打开。
3. 若 macOS 提示无法验证开发者或应用未公证，确认文件来自本仓库且可信后，进入「系统设置 → 隐私与安全性」，找到该应用的拦截提示，点击「仍要打开」，按系统提示确认。参见 [Apple 官方安装说明](https://support.apple.com/102445)。

附件 `SHA256SUMS.txt` 用于校验下载完整性。将它与 ZIP 放在同一目录，打开终端进入该目录后运行：

```sh
shasum -a 256 -c SHA256SUMS.txt
```

结果应显示 ZIP 文件名及 `OK`。

## 快速开始

1. 连接 MIDI 设备，将设备时钟源设为 USB MIDI / External，并开启接收 Start/Stop。
2. 打开应用。系统 MIDI 输出会显示在列表中，设备默认「跟随主控」，不会自动播放。
3. 设置顶部 BPM（20–300），按 Enter 确认，再点击「开始」，启动跟随主控的设备。
4. 需要单独控制时，将设备切换为「独立控制」，使用该设备自己的 BPM、开始和停止。切换到独立模式不会中断当前播放。
5. 主控停止只影响跟随设备；右上角「全部停止」停止所有设备，包括独立设备。

切回「跟随主控」会采用主控速度和播放状态，不会强制重置已播放设备的音序位置。若需从头对齐，请先停止主控后统一开始。设备断线或发送失败只影响该设备；重连后保持停止，可点击「加入同步」。

## 调速与快捷键

- 点击 BPM 数字编辑；Enter 或点击外部确认，Esc 取消。编辑中 ↑ / ↓ 每次调整草稿 0.1 BPM，确认后才应用。
- 加减按钮短按调整 0.1 BPM，长按约 0.4 秒后连续调整并逐渐加速，松开或移出按钮停止。
- 没有编辑输入框时，↑ / ↓ 调整主控 BPM，支持长按加速，不改变独立设备。
- ⌘Return：开始主控；⌘.：停止主控；⇧⌘.：全部停止。
- 右上角主题菜单可选择跟随系统、浅色或深色。窗口固定宽度 380 pt，高度可调、内容可滚动。

## 功能与限制

- 24 PPQN MIDI 时钟，基于 host time 的绝对时间轴；主控共同排程启停，每设备独立调度与故障隔离。
- 保存主控速度、按设备 ID 保存独立速度，以及主题偏好。
- 展示系统 MIDI 输出，包括 USB、接口及虚拟端口。避免重复路由导致同一硬件收到两路时钟。
- 尚不支持 Continue、Tap Tempo、每设备延迟补偿或速度比例。
- 软件发送状态不代表硬件确认同步；USB 路径和外设处理会影响实际时序，本应用不提供硬实时保证。
