# MIDI Clock Controller v0.1.1

本次更新加入 MIDI Continue，整理播放操作、菜单和窗口布局。

## 更新内容

- 停止后可选择「继续播放」，发送 MIDI Continue（FB），保留设备自己的停止位置；「从头开始」仍发送 Start（FA）。
- 主按钮随状态显示「开始播放 / 停止 / 继续播放」，可继续时显示次要的从头开始操作。
- 主控继续只恢复符合条件的跟随设备；独立设备保持独立控制。故障或断线后清除继续资格，重连后需手动从头开始。
- 新增「播放」菜单、外观菜单、设备刷新快捷键，以及应用内使用指南。
- 统一标题栏与窗口背景，整理主控布局和空设备提示。
- 新增可重复使用的 DMG 打包脚本，自动读取应用版本并生成 SHA-256 校验文件。

## 下载与安装

需要 **Apple Silicon（M 系列芯片）Mac、macOS 13 或更高版本**。本次不提供 Intel 二进制版本；运行无需安装 Xcode 或第三方依赖。

1. 下载附件 `MIDI-Clock-v0.1.1-macOS-arm64.dmg`，双击打开。
2. 将 `MIDI Clock.app` 拖到旁边的 `Applications` 文件夹。升级时先退出旧版，再替换「应用程序」中的同名应用。
3. 拷贝完成后推出磁盘映像，从「应用程序」启动。

应用使用 ad-hoc 签名，尚未使用 Developer ID 签名或 Apple 公证。若首次打开被拦截，确认下载来源可信后，进入「系统设置 → 隐私与安全性」，找到对应提示并选择「仍要打开」。参见 [Apple 官方说明](https://support.apple.com/102445)。

将 DMG 与附件中的同名 `.dmg.sha256` 文件放在同一目录，在该目录运行：

```sh
shasum -a 256 -c MIDI-Clock-v0.1.1-macOS-arm64.dmg.sha256
```

结果应为 `OK`。GitHub 自动提供的 Source code 附件是源码，不是安装包。

## 使用

1. 连接 MIDI 设备，将硬件时钟设为 USB MIDI / External，并开启接收 Start / Continue / Stop。
2. 设备默认跟随主控，不自动播放。设置顶部 BPM（20–300），确认后点击「开始播放」。
3. 点击「停止」后，可用「继续播放」恢复设备位置，或用「全部从头开始」重置跟随设备的播放起点。
4. 需要单独调速和启停时，将对应设备切换为「独立控制」。主控操作只影响跟随设备；顶部「全部停止」影响所有设备。
5. 从「帮助 → MIDI Clock 使用指南」查看操作说明；查看指南不会中断播放。

点击 BPM 数字编辑，Enter 或点击外部确认，Esc 取消；编辑中上下键微调草稿。未编辑时上下键调整主控速度。加减按钮和非编辑态上下键均支持长按加速。

| 快捷键 | 操作 |
| --- | --- |
| ⌘Return | 开始或继续主控 |
| ⇧⌘Return | 停止后让跟随设备全部从头开始 |
| ⌘. | 停止主控 |
| ⇧⌘. | 全部停止 |
| ⌘R | 刷新 MIDI 设备 |

## 已知限制

Continue 保留各设备各自的停止位置，不保证乐曲位置一致；停止期间不发送 Clock，继续时使用当前 BPM，不补发停止期间的脉冲。断线或故障后须从头开始。

本应用输出 24 PPQN MIDI 时钟，软件发送状态不代表硬件已确认同步，也不提供硬实时保证。暂不支持 Tap Tempo、每设备延迟补偿或速度比例。避免重复路由让同一设备收到两路时钟。

问题反馈请附 macOS 版本、芯片型号、设备型号和复现步骤：[GitHub Issues](https://github.com/lenuxo/midi-clock-controller/issues)。
