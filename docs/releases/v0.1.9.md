# MIDI Clock Controller v0.1.9

This release adds **Check for Updates…** to the app menu and in-app updates powered by Sparkle 2.10.1. The update window shows the available version and release notes. You can download an update, then choose **Install and Relaunch** to replace the app and restart it.

Downloading keeps MIDI playback running. Confirming installation stops all local MIDI outputs and disables Link Start/Stop sync before the app quits. Update archives and feeds are verified with the app's built-in EdDSA public key. Checks run only when requested; background checks and automatic installation are disabled. Releases without an update feed offer their GitHub download page.

## Install

Requires **Apple Silicon and macOS 13 or later**. Users of v0.1.8 and earlier need to install v0.1.9 manually once to receive the new updater. Quit the previous version, open the DMG, and drag **MIDI Clock Controller** into **Applications**. Future releases that include a signed update feed can then be installed from the app menu.

The app uses an ad-hoc signature and has not been notarized. If macOS blocks first launch, verify the download and use **System Settings → Privacy & Security → Open Anyway**.

## Downloads and source

- **DMG** — manual installation.
- **ZIP + appcast.xml** — signed in-app update package and feed.
- **Source archive** — GPL-2.0-or-later corresponding source, including pinned Link and Asio headers, Sparkle package lock, resources, and build scripts.

Download the matching checksum file to verify an archive. For example:

```sh
shasum -a 256 -c MIDI-Clock-Controller-v0.1.9-macOS-arm64.dmg.sha256
```

To build from source on macOS, run `zsh scripts/build-app.sh`. The first build downloads the pinned Sparkle dependency. Creating signed updates requires the publisher's private signing key; see `docs/updates.md`.

## Verification

82 tests passed, including private-port CoreMIDI integration tests. Two Link tests that require an isolated network were skipped. Signed update archives and feeds were verified, and a modified archive was rejected. An isolated preview app successfully downloaded, installed, and relaunched from version 0.0.1 to 0.0.2 using simulated MIDI devices.
