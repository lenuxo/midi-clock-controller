# MIDI Clock Controller v0.1.3

## What's new

- Switch devices between **Follow** and **Independent** directly with a two-part control. The active mode is highlighted; clicking it again does not change playback.
- **Continue** and **Restart** now sit side by side with equal-sized buttons, for both master and independent device controls.
- Updated English and Chinese labels and accessibility descriptions.

This update focuses on controls and layout; MIDI clock scheduling and transport behavior are unchanged.

## Install or upgrade

Requires **Apple Silicon and macOS 13 or later**.

1. Download `MIDI-Clock-Controller-v0.1.3-macOS-arm64.dmg` and open it.
2. Quit the existing app, then drag **MIDI Clock Controller.app** into **Applications**, replacing the previous copy.
3. Eject the disk image and launch the app from Applications.

The app is ad-hoc signed and **not notarized**. If macOS blocks the first launch, confirm that you trust the download, then use **System Settings → Privacy & Security → Open Anyway**. See [Apple's instructions](https://support.apple.com/102445).

Download the accompanying checksum file into the same directory as the DMG:

```sh
shasum -a 256 -c MIDI-Clock-Controller-v0.1.3-macOS-arm64.dmg.sha256
```

## Validation

37 automated tests passed, including CoreMIDI integration on private virtual ports. English/light and Chinese/dark previews were checked for the new button layout, mode switching, repeated selection, keyboard stop, and scrolling. The DMG's app contents, signature, version `0.1.3`, and build `4` were verified. Physical MIDI hardware was not tested.

## 使用与更新说明

本版将设备模式菜单改为直接可见的「跟随 / 独立」分段切换，并将「继续播放 / 从头开始」改为等宽并排按钮，适用于主控和独立设备。同步更新中英文文案与辅助功能描述；MIDI 调度和播放语义不变。

需要 Apple Silicon、macOS 13+。退出旧版后，打开 DMG，将应用拖入 Applications 并替换旧副本。应用尚未公证；首次打开如被拦截，请确认来源可信后，在「系统设置 → 隐私与安全性」中选择「仍要打开」。

连接设备后，将硬件时钟设为 USB MIDI / External，并开启 Start / Continue / Stop 接收。在应用中设置 BPM 并开始播放；设备默认跟随主控，也可独立控制。「全部停止」覆盖所有设备。

Continue preserves each device's own stopped position, not a shared song position. Reconnected devices never start automatically. Hardware synchronization depends on devices and USB paths; this is not a hard real-time guarantee.
