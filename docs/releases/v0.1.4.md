# MIDI Clock Controller v0.1.4

## What's new

- Disconnected devices are dimmed and disabled, then removed from the list after 30 seconds. Refreshing does not extend the countdown; reconnecting cancels removal.
- Reconnected devices remain stopped. If a removed device returns, it joins as a new connection following the master, without starting playback automatically.
- Fixed switching back to **System** appearance after manually choosing Light or Dark, including native window appearance and title text.
- Added regression coverage for disconnect cleanup, stale callbacks, shutdown cancellation, and appearance inheritance.

## Install or upgrade

Requires **Apple Silicon and macOS 13 or later**.

1. Download `MIDI-Clock-Controller-v0.1.4-macOS-arm64.dmg`.
2. Quit the existing app, open the DMG, and drag **MIDI Clock Controller.app** into **Applications**, replacing the old copy.
3. Eject the disk image and launch the app from Applications.

The app is ad-hoc signed and **not notarized**. If macOS blocks the first launch, confirm that you trust this download, then use **System Settings → Privacy & Security → Open Anyway**. See [Apple's instructions](https://support.apple.com/102445).

Download the checksum file into the same directory as the DMG and run:

```sh
shasum -a 256 -c MIDI-Clock-Controller-v0.1.4-macOS-arm64.dmg.sha256
```

## Validation

41 automated tests passed, including CoreMIDI integration using private virtual ports, disconnect cleanup, and native appearance regression tests. A hardware-free preview confirmed disabled disconnected controls, subsequent removal, and switching from Dark back to System appearance. DMG contents, app signature, version `0.1.4`, and build `5` were verified. Physical MIDI hardware was not tested.

## 中文说明

本版完善断线设备管理：断开后整卡置灰、禁用操作，30 秒内未重连则移出列表并释放对应资源。重复刷新不会延长期限，期间重连会取消移除；重连后不会自动播放。

修复手动选择浅色或深色后，切回「跟随系统」仍保留旧外观的问题，并同步原生窗口和标题文字显示。

需要 Apple Silicon、macOS 13+。退出旧版后打开 DMG，将应用拖入 Applications 替换旧副本。应用尚未公证；首次打开如被拦截，请确认来源可信后，从「系统设置 → 隐私与安全性」选择「仍要打开」。

连接设备后，将硬件时钟源设为 USB MIDI / External，并开启 Start / Continue / Stop 接收。在应用中设置 BPM 并开始播放。主控只影响跟随设备，「全部停止」覆盖所有设备。

Continue preserves each device's own stopped position, not a shared song position. Hardware synchronization depends on devices and USB paths; this is not a hard real-time guarantee.
