# MIDI Clock Controller v0.1.2

## What's new

- English and Simplified Chinese interfaces, including menus, help, and MIDI error messages. Choose a language from the app menu and relaunch to apply it.
- Interface zoom from 80% to 150%, with saved preferences and keyboard shortcuts.
- A consistent DSEG7 Classic tempo display for both viewing and editing, with improved selection colors and device layout.
- Updated app name: **MIDI Clock Controller** / **MIDI时钟控制器**, with version and author information in About.
- Shorter documentation: English README by default, with a linked Chinese edition.

Master and independent device control, Start / Continue / Stop, and 24 PPQN MIDI clock remain available.

## Install or upgrade

Requires **Apple Silicon and macOS 13 or later**.

1. Download `MIDI-Clock-Controller-v0.1.2-macOS-arm64.dmg` and open it.
2. Quit the previous app, then drag **MIDI Clock Controller.app** into **Applications**.
3. Eject the disk image and open the app from Applications.

Earlier releases used the name **MIDI Clock.app**. If that copy remains in Applications, remove it after confirming the new app works, and update any Dock shortcut. The bundle identifier is unchanged so existing preferences can be reused.

This release is ad-hoc signed and **not notarized**. If macOS blocks the first launch, confirm that you trust this download, then use **System Settings → Privacy & Security → Open Anyway**. See [Apple's instructions](https://support.apple.com/102445).

Download the accompanying checksum file into the same directory as the DMG, then verify:

```sh
shasum -a 256 -c MIDI-Clock-Controller-v0.1.2-macOS-arm64.dmg.sha256
```

## Get started

Set your hardware's clock source to **USB MIDI / External**, enable Start / Continue / Stop reception, choose a BPM, and start playback. Devices follow the master by default; switch a device to independent control for its own tempo and transport. **Stop All** stops every device.

Continue preserves each device's own stopped position; it does not align song positions. Reconnected devices never start automatically. Use the in-app Help menu for more details.

## Validation

37 automated tests passed, including CoreMIDI integration through private virtual ports, localization, zoom, and font tests. The DMG was mounted and its app signature and contents verified. English/light and Chinese/dark previews, 150% zoom, scrolling, and tempo text selection were checked without connecting to MIDI hardware. Physical-device synchronization was not tested.
