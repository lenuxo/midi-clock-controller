# MIDI Clock Controller v0.1.7

## Changes

- Simplify the Ableton Link panel with one heading and Join/Leave controls in the same row.
- Show shared tempo in the master display; retain the original Link tempo and ratio only when MIDI tempo conversion is needed.
- Update English and Chinese documentation to match the compact layout.

## Install and use

Requires **Apple Silicon and macOS 13 or later**. Quit the old app, open `MIDI-Clock-Controller-v0.1.7-macOS-arm64.dmg`, and drag **MIDI Clock Controller.app** into **Applications**, replacing the previous copy. Eject the DMG and launch from Applications.

The app is ad-hoc signed and **not notarized**. If macOS blocks the first launch, confirm that you trust the download, then use **System Settings → Privacy & Security → Open Anyway**.

Connect MIDI hardware and select USB MIDI / External clock on the device. Set the tempo and start playback. To use Link, stop the master and click **Join** in the Link Session card. **Transport → Local / Linked** controls optional Start/Stop sync; **MIDI launch → Next beat / Every 4 beats** controls the start boundary. Joining never starts playback automatically. **Stop All** stops local MIDI and disables transport sync.

Download the checksum alongside the DMG and verify with:

```sh
shasum -a 256 -c MIDI-Clock-Controller-v0.1.7-macOS-arm64.dmg.sha256
```

## Source and validation

Distributed under **GPL-2.0-or-later**. The attached `MIDI-Clock-Controller-v0.1.7-source.tar.gz` contains the complete corresponding source, pinned Link/Asio dependencies, resources, licenses, and build scripts. On macOS with Swift 5.9+, a macOS SDK and C++17 support, run `zsh scripts/build-app.sh`, then `zsh scripts/build-dmg.sh`.

68 tests passed, with two opt-in real Link network tests skipped. Private-port CoreMIDI integration tests were required and passed. The DMG passed integrity verification; its mounted app passed signature verification and matched the build. Debug preview checks covered light/dark appearance, compact layout, scrolling, and keyboard transport. Real Link network discovery and physical MIDI/audio alignment remain unverified.
