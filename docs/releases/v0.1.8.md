# MIDI Clock Controller v0.1.8

Following devices gradually return to their shared clock grid after a late scheduler wakeup. Stop All schedules stops across the local outputs before waiting for delivery. Rapid Link Stop/Play changes are handled in order, and delayed local callbacks no longer replay a command.

If another Link participant changes tempo while you edit BPM, cancelling or confirming an unchanged field preserves the new tempo. **Refresh MIDI Devices** retries discovery after a MIDI initialization failure.

## Install and use

On Apple Silicon with macOS 13 or later, quit the previous version, open the DMG and drag **MIDI Clock Controller** into **Applications**. The app uses an ad-hoc signature and has not been notarized. If macOS blocks first launch, verify the download and use **System Settings → Privacy & Security → Open Anyway**.

Set the device clock to **External / USB MIDI**, choose a BPM and start playback. To share the beat over Link, stop the master and click **Join**. Choose **Linked** on both peers to share Start/Stop commands.

Download the matching checksum beside the DMG and run `shasum -a 256 -c MIDI-Clock-Controller-v0.1.8-macOS-arm64.dmg.sha256`. The GPL-2.0-or-later source archive includes the pinned dependencies. Extract it and run `zsh scripts/build-app.sh` followed by `zsh scripts/build-dmg.sh` to rebuild on macOS.

75 tests passed, including the private-port CoreMIDI tests. Two Link tests require an isolated network and were skipped. Physical device timing was not measured.
