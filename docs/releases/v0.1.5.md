# MIDI Clock Controller v0.1.5

## What's new

- **Ableton Link to MIDI Clock**: following MIDI devices can use a shared Link beat timeline; independent devices keep their own tempo and transport.
- Choose next-beat or 4-beat launch alignment, with cancellable queued starts and optional Start/Stop sync (off by default).
- Device cards distinguish the MIDI output protocol from its beat source. Link peers are counted separately from MIDI hardware.
- Out-of-range Link tempos use a power-of-two ratio to keep MIDI within 20–300 BPM.
- The project is now distributed under **GPL-2.0-or-later**. Full corresponding source, pinned SDK headers, resources, notices, and build scripts are included in the source attachment.

## Install or upgrade

Requires **Apple Silicon and macOS 13 or later**. Quit the old app, open `MIDI-Clock-Controller-v0.1.5-macOS-arm64.dmg`, and drag **MIDI Clock Controller.app** into **Applications**. Replace the old copy, eject the image, and launch from Applications.

The app is ad-hoc signed and **not notarized**. If macOS blocks the first launch, confirm that you trust the download, then use **System Settings → Privacy & Security → Open Anyway**. See [Apple's instructions](https://support.apple.com/102445).

Download the DMG checksum into the same directory and run:

```sh
shasum -a 256 -c MIDI-Clock-Controller-v0.1.5-macOS-arm64.dmg.sha256
```

## Using Link

Stop the master, then enable **Link**. Allow local network access if prompted and enable Link in another app on the same network. Joining never starts MIDI playback automatically. Use Link Settings for launch alignment and optional **Sync Start / Stop**. Master BPM edits change the shared tempo; independent-device edits remain local.

**Stop All** stops local MIDI and disables Start/Stop sync without stopping remote Link peers. Link starts disabled on every app launch. See the [Link guide](https://github.com/lenuxo/midi-clock-controller/blob/v0.1.5/docs/ableton-link.en.md) for details. Continue preserves each device's own stopped position; it does not align song positions.

## Validation

The final full run passed 62 tests with 1 opt-in real Link network test skipped. Private-port CoreMIDI integration and offline official-SDK timeline tests passed. The first run hit timing assertions in the MIDI tempo-change integration test; both a targeted rerun and the subsequent full run passed. Real Link peer discovery on an isolated network and physical MIDI/audio alignment remain unverified. Simulated Link/MIDI UI checks do not replace those tests.
