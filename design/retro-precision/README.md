# 历史视觉参考

- `ui-quiet-v3.png` / `design-spec-v3.json`：更平面的备选方案。

JSON 保留各提案原始说明。其中宽屏适配、独立加减键等内容已被后续固定窄窗口和一体化速度模块替代；请勿直接当作当前需求。
